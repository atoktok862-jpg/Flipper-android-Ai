# Pocket Multitool — ретро-мультитул для Xiaomi Redmi 12

Нативный Android-проект на Kotlin: карманная ретро-консоль с янтарным монохромным экраном, пиксельным кибер-лисом и аппаратными модулями, которые реально используют IR, NFC, BLE, Wi-Fi, USB-OTG, AudioTrack и вспышку камеры.

Целевое устройство: Xiaomi Redmi 12 (Android 13/14). Проект также собирается и на других Android-устройствах с API 23+, но доступность функций зависит от железа — приложение показывает это в разделе «Диагностика».

## Что внутри

| Раздел | Возможности |
| --- | --- |
| ИК-Пульт | `ConsumerIrManager`, база NEC-кодов Samsung, LG, Xiaomi, Sony, Philips, BBK; Питание, Громкость ±, Каналы ±, Mute; ручной NEC-код и RAW-импульсы с заданной несущей |
| NFC Менеджер | UID, технологии NfcA/MifareClassic/IsoDep/Ndef, содержимое NDEF, локальная база JSON в SharedPreferences, запись текста и URL на пустые NDEF-метки |
| Карты и Коды | генератор QR, EAN-13 и Code-128 через ZXing; сохранение карт; автоматическая максимальная яркость экрана при показе кода |
| Радио-сканер | BLE-устройства с именем, MAC и RSSI в дБм; Wi-Fi-сети с SSID, каналом, диапазоном 2.4/5 ГГц и уровнем сигнала |
| USB-OTG Терминал | `UsbManager`, запрос разрешения, выбор устройства, 9600/115200 бод, CDC-ACM `SET_LINE_CODING`, bulk IN/OUT, текстовый журнал |
| Инструменты | синусоидальный генератор 20–20000 Гц на `AudioTrack`; азбука Морзе и тест вспышки через `CameraManager.setTorchMode`; вибрация |
| Диагностика | реальная проверка `hasIrEmitter()`, NFC, BLE, Wi-Fi, USB Host, камеры, вибратора, версии Android и модели устройства |

Управление: аппаратные кнопки **ВВЕРХ / ВНИЗ / ОК / НАЗАД** внизу экрана, касание по строке — выбор, повторное касание по выбранной строке — вход, свайп вверх/вниз — прокрутка. Кнопки и сам экран имеют тактильный отклик (вибрация).

## Сборка APK бесплатно через GitHub Actions

Android Studio не нужна.

1. Создайте репозиторий на GitHub.
2. Загрузите в него всё содержимое папки `PocketMultitoolAndroid` (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** → workflow **Build debug APK** → **Run workflow** (или просто сделайте `git push`; workflow запускается сам).
4. Дождитесь зелёной галочки (обычно 3–7 минут).
5. Откройте последний запуск → в блоке **Artifacts** скачайте `app-debug`.
6. Распакуйте архив, получите `app-debug.apk` и установите его на телефон: откройте файл на устройстве или выполните `adb install -r app-debug.apk`.

Workflow использует JDK 17, Android SDK 34, Gradle 8.7 и загружает готовый `app-debug.apk` как артефакт. Лимитов бесплатного аккаунта GitHub достаточно.

## Локальная сборка

Нужны JDK 17, Android SDK Platform 34, Build Tools 34.0.0 и Gradle 8.7.

```powershell
gradle wrapper --gradle-version 8.7
.\gradlew assembleDebug
```

Файл `gradle-wrapper.jar` в репозиторий не включён, поэтому команду `gradle wrapper` нужно выполнить один раз перед первым использованием `gradlew`. После этого APK будет здесь:

```text
app\build\outputs\apk\debug\app-debug.apk
```

В Android Studio достаточно открыть корень проекта и нажать **Run**; Studio сама подтянет зависимости из `google()` и `mavenCentral()`.

## Использование модулей

### ИК-Пульт

Выберите бренд → кнопку команды. Для нестандартного телевизора используйте **RAW / NEC ВРУЧНУЮ**:

- NEC-код: 8 hex-цифр, например `E0E040BF`. Приложение само строит импульсы 38 кГц.
- RAW-импульсы: несущая в Гц и список длительностей в микросекундах через запятую, например `9000,4500,560,560,560`. Последовательность должна быть чередованием «включено/выключено».

Диапазон несущих берётся из `getCarrierFrequencies()` конкретного устройства. Встроенные коды — распространённые NEC-значения; у разных моделей телевизоров они могут отличаться, поэтому RAW-режим является основным способом точного подбора.

### NFC Менеджер

Раздел **Читать метку** переводит приложение в режим foreground dispatch — просто поднесите метку к задней панели. Для записи выберите **Записать текст** или **Записать ссылку**, введите данные и поднесите пустую NDEF-метку. Пустые метки без NDEF будут отформатированы через `NdefFormatable`, если метка это поддерживает. Защищённые от записи метки не перезаписываются.

База меток хранится локально в `SharedPreferences` как JSON и не отправляется в сеть.

### Карты и Коды

Добавьте карту: название → номер → формат. Для EAN-13 можно ввести 12 цифр — контрольная цифра рассчитается автоматически, или 13 цифр — тогда она будет проверена. При открытии карты яркость экрана временно выставляется на максимум и восстанавливается при выходе.

### Радио-сканер

BLE-сканирование на Android 12 и новее запрашивает `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`, на более старых — `ACCESS_FINE_LOCATION`. Wi-Fi-сканирование всегда требует геолокации. Сканирование BLE автоматически останавливается через 20 секунд. Android может ограничивать частоту вызовов `startScan()`, поэтому результаты появляются не мгновенно.

### USB-OTG Терминал

Подключите устройство через OTG-переходник, откройте раздел, выберите устройство и нажмите **Открыть порт**. Система покажет стандартный диалог разрешения USB. Скорость 9600/115200 задаётся командой CDC-ACM `SET_LINE_CODING`, поэтому корректно работает с USB-UART адаптерами класса CDC. Для адаптеров с проприетарным протоколом (FTDI, CH340 и подобные) скорость задаётся их прошивкой, но обмен через bulk-конечные точки остаётся доступным.

### Инструменты

Генератор тона использует 48 кГц и амплитуду без клиппинга. Морзе передаётся вспышкой камеры; длительность точки — 90 мс (для теста — 150 мс). Если камера используется другим приложением, передача может быть недоступна.

## Разрешения

В манифесте объявлены `TRANSMIT_IR`, `NFC`, `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `CAMERA`, `VIBRATE`, `USB_PERMISSION`, `INTERNET` и `WAKE_LOCK`. Опасные разрешения запрашиваются только при первом использовании соответствующей функции. Все `<uses-feature>` помечены как `required="false"`, чтобы приложение можно было установить на устройства без части железа.

## Ограничения

- Реальные коды ИК зависят от модели телевизора — используйте RAW-режим.
- Запись NFC доступна только для NDEF-совместимых меток.
- Wi-Fi и BLE зависят от ограничений Android на фоновое сканирование.
- USB-терминал работает с текстовыми bulk-командами, а не с драйверами конкретных чипов.
- Вспышка занимает камеру, поэтому параллельная съёмка невозможна.

Проект не использует Google Play Services и не отправляет данные наружу.
